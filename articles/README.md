# Articles

Longer-form writing that sits beside the data. Two kinds live here, and they are kept
apart on purpose:

- **Reference explainers** cite the documents this repository already uses and add
  nothing that is not in `data/`.
- **Opinion** is the author's argument. It is labelled as opinion and never treated as a
  source by the dataset.

| [`project-2025-antithesis.md`](project-2025-antithesis.md) | opinion (owner's essay) | **not yet included — see the note in the file** |

## Why the opinion is separate

A public-accountability dataset loses its value the moment a reader cannot tell a
documented fact from an argument. The data files answer "what does the document say";
the essay answers "what should be done about it". Mixing them would make every row
disputable on political grounds instead of evidentiary ones.
